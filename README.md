# Mission AF-27

A one-page mission file for my application to ispace's internship in Tokyo, starting February 2027.

Live: https://heilko.github.io/ispace/

Click the rocket to launch. The Moon is a real 3D globe built from NASA's LRO maps (CGI Moon Kit, NASA's Scientific Visualization Studio), rendered with three.js; the light follows your scroll, and "Tonight's Moon" shows today's real phase.
